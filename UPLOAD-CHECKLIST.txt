ADios — GitHub upload checklist (AlexRabbit)
============================================

Upload ONLY these files/folders. Do NOT upload .git unless you use git push directly.

REQUIRED — launchers & docs
  ADios.bat
  ADios.sh
  README.md
  LICENSE
  .gitignore

REQUIRED — build engine
  config/build_hosts.py
  config/lists
  config/blacklist
  config/whitelist
  config/remover
  config/probe_cache

REQUIRED — blocklist outputs (users download these)
  hosts
  pihole-hosts
  dnscrypt-hosts
  adguardhosts.txt
  remover.txt

REQUIRED — auto-update
  .github/workflows/update-hosts.yml

DO NOT UPLOAD
  .git/              (optional — use git push instead of manual zip)
  __pycache__/
  .cursor/
  .vscode/
  *.log
  *.tmp
  *.bak

NO SECRETS IN REPO
  No API keys, tokens, passwords, or private paths found.
  config/ contains only public blocklist URLs.

FIRST TIME ON GITHUB
  1. Upload all files above
  2. Enable GitHub Actions (Settings → Actions → Allow)
  3. Actions → "Update hosts" → Run workflow (optional immediate rebuild)
  4. Every 48h GitHub Actions updates hosts, remover.txt, probe_cache automatically

LOCAL USE (Windows)
  Double-click ADios.bat — rebuilds everything in this folder.
